## Overview
The **Mindfulness Program** is a console-based application that helps users practice mindfulness activities. It demonstrates core object-oriented programming principles, including:

- **Abstraction** – Each activity has its own class with relevant attributes.  
- **Encapsulation** – Member variables are private or protected.  
- **Inheritance** – Specific activities inherit from a base `Activity` class.  
- **Polymorphism** – Shared methods like `Start()` and `End()` are reused.

---

## Activities
1. **Breathing Activity** – Guides the user through a series of timed breathing exercises.  
2. **Listing Activity** – Prompts the user to list items (e.g., things that make them happy) and counts them.  
3. **Reflecting Activity** – Encourages the user to reflect on positive experiences with a timed pause.

---

## Features / Creativity
- Spinner animation to indicate progress.  
- Countdown before starting each activity.  
- Color-coded text for a better user experience.  
- Dynamic user input in the Listing activity.  
- Clean console output for readability.
